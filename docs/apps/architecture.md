# Portal 2.0 Architecture

## Goal

Centralize all client work, requests, issues, phases, and communication.

---

## Core Objects

### Company

Represents a client/business.

Examples:
- Novel eShelf
- SMTS
- BeeDev

---

### Project

Represents a major initiative.

Examples:
- Author Platform
- Reader Platform
- Mobile App

---

### Phase

Represents a milestone.

Examples:
- Phase 1 Author Launch
- Phase 2 Reader Launch

---

### Sprint

Represents a work period.

Examples:
- Sprint 1
- Sprint 2

---

### Request

Represents work that needs to be done.

Sources:
- Client Portal
- Public Form
- Email
- Discord
- Meeting
- Staff

Types:
- Bug
- Feature
- Content
- Design
- DevOps
- Question

---

### Update Log

Client-facing project updates.

---

### Dashboard

Staff:
- My Work
- Unassigned
- Waiting on Client
- Blocked

Client:
- My Projects
- My Requests
- Recent Updates
